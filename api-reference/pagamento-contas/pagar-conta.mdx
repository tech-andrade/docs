---
title: "Pagar boleto ou conta"
api: "POST /baas/api/v1/bill-payments"
description: "Pague um boleto, conta de consumo ou tributo informando o valor e o código de barras ou a linha digitável."
---

<Note>
Para o passo a passo completo, veja o guia [Pagar boleto ou conta](/guias/pagamento-contas/pagar).
</Note>

<Warning>
O pagamento é assíncrono. A resposta `200` indica que o pagamento foi aceito para processamento, mesmo com `status` igual a `PAID`. Não há webhook de confirmação. Se o pagamento não for liquidado, o valor volta para a sua conta e o time da Delfinance entra em contato.
</Warning>

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta Delfinance.
</ParamField>

<ParamField header="IdempotencyKey" type="string" required>
  GUID único por requisição. Evita pagamentos duplicados em caso de retry.
</ParamField>

## Body

<ParamField body="amount" type="number" required>
  Valor a pagar. Use o `chargedAmount` da consulta ou, se o documento aceitar pagamento parcial, um valor entre `minimumPaymentAmount` e `maximumPaymentAmount`.
</ParamField>

<ParamField body="barCode" type="string">
  Código de barras. Obrigatório se você não enviar `digitableLine`.
</ParamField>

<ParamField body="digitableLine" type="string">
  Linha digitável. Obrigatória se você não enviar `barCode`.
</ParamField>

## Response

<ResponseField name="id" type="string">Identificador do pagamento.</ResponseField>
<ResponseField name="identifierNumber" type="string">Identificador do documento.</ResponseField>
<ResponseField name="barCode" type="string">Código de barras.</ResponseField>
<ResponseField name="digitableLine" type="string">Linha digitável.</ResponseField>
<ResponseField name="status" type="string">Status do pagamento.</ResponseField>
<ResponseField name="dueDate" type="string">Data e hora de vencimento do documento.</ResponseField>
<ResponseField name="createdAt" type="string">Data e hora em que o pagamento foi criado, em ISO 8601.</ResponseField>
<ResponseField name="originalAmount" type="number">Valor original do documento.</ResponseField>
<ResponseField name="paidAmount" type="number">Valor enviado no pagamento.</ResponseField>
<ResponseField name="paymentCalculation" type="object">Valores calculados do documento. Os campos são os mesmos da [consulta](/api-reference/pagamento-contas/consultar-conta).</ResponseField>
<ResponseField name="beneficiary" type="object">Dados do beneficiário.</ResponseField>
<ResponseField name="issuer" type="object">Dados do banco emissor.</ResponseField>

<RequestExample>
```bash cURL
curl --location 'https://apisandbox.delbank.com.br/baas/api/v1/bill-payments' \
--header 'IdempotencyKey: {{$guid}}' \
--header 'Content-Type: application/json' \
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}' \
--data '{
    "amount": 691.71,
    "barCode": "43596938200000691710001112000000200000309361"
}'
```
</RequestExample>
