---
title: "Listar recebimentos com split"
api: "GET /baas/api/v1/split-payments/orders"
description: "Liste os pagamentos da conta de recebimento que geraram repasses, com os valores usados no cálculo dos repasses."
tag: "BETA"
---

<Warning>
**Funcionalidade em beta.** Contrato em proposta, sujeito a mudanças. Veja o guia [Acompanhar repasses](/guias/split-pagamentos/acompanhar-repasses).
</Warning>

Retorna, de forma paginada, os recebimentos com split da conta de recebimento informada em `x-delfinance-account-id`. Cada item traz os valores usados no cálculo dos repasses. Para ver os repasses, use [Consultar recebimento com split](/api-reference/split-pagamentos/consultar-recebimento).

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta de recebimento.
</ParamField>

## Query params

<ParamField query="startDate" type="string" required>
  Data inicial do recebimento, no formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="endDate" type="string" required>
  Data final do recebimento, no formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="source" type="string">
  Origem das instruções: `ACCOUNT_CONFIGURATION` (split padrão da conta) ou `QR_CODE` (split por cobrança).
</ParamField>

<ParamField query="page" type="number" default="1">
  Número da página (começa em 1).
</ParamField>

<ParamField query="limit" type="number" default="20">
  Itens por página. Máximo de 100.
</ParamField>

## Response

Array de recebimentos com split. Os dados de paginação vêm no header `Pagination`, descrito em [Paginação](#paginação).

<ResponseField name="id" type="string">
  Identificador do recebimento com split. É o id da transação de crédito que gerou os repasses, o mesmo do extrato e do webhook de recebimento.
</ResponseField>

<ResponseField name="source" type="string">
  `ACCOUNT_CONFIGURATION` (split padrão da conta) ou `QR_CODE` (split por cobrança).
</ResponseField>

<ResponseField name="grossAmount" type="number">
  Valor integral do pagamento recebido.
</ResponseField>

<ResponseField name="tariffAmount" type="number">
  Tarifa de split descontada antes do cálculo. `0` quando não há.
</ResponseField>

<ResponseField name="splitBaseAmount" type="number">
  Base de cálculo dos repasses (`grossAmount - tariffAmount`).
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data e hora do recebimento, em ISO 8601.
</ResponseField>

## Paginação

A resposta é um array. Os dados de paginação vêm no header `Pagination`:

```text Header
Pagination: {"currentPage":1,"pageSize":20,"pageCount":1,"rowCount":1,"totalAmount":200.00}
```

| Campo | Descrição |
|---|---|
| `currentPage` | Página retornada |
| `pageSize` | Itens por página (`limit`) |
| `pageCount` | Total de páginas |
| `rowCount` | Total de recebimentos encontrados |
| `totalAmount` | Soma do `grossAmount` de todos os recebimentos encontrados, considerando todas as páginas |

<RequestExample>
```bash cURL
curl --location 'https://apisandbox.delbank.com.br/baas/api/v1/split-payments/orders?startDate=2026-10-01&endDate=2026-10-26&page=1&limit=20' \
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}'
```
</RequestExample>
