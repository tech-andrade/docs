---
title: "Consultar ordens de split"
api: "GET /api/v1/external/split-payments/orders"
description: "Busque uma ordem específica ou liste ordens por transação, página e limite."
---

<Note>
Para o contexto completo, veja o guia [Ordens de Split de Pagamentos](/guias/split-pagamentos/ordens).
</Note>

Retorna uma ordem específica ou uma listagem paginada de ordens associadas à credencial autenticada.

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

## Query params

<ParamField query="id" type="string">
  Identificador da ordem a ser consultada.
</ParamField>

<ParamField query="transactionId" type="string">
  Identificador da transação original de cash-in associada à ordem.
</ParamField>

<ParamField query="page" type="number" default="1">
  Página da listagem. Padrão: `1`.
</ParamField>

<ParamField query="limit" type="number" default="10">
  Quantidade de itens por página. Padrão: `10`; valores maiores que `100` são limitados a `100`.
</ParamField>

<ParamField query="include" type="string">
  Quando definido como `metadata`, retorna os itens em `data` e os metadados de paginação em `metadata`.
</ParamField>

## Response

<ResponseField name="id" type="number" required>
  Identificador único da ordem.
</ResponseField>

<ResponseField name="transactionOriginalId" type="string" required>
  Identificador da transação original do cash-in relacionado.
</ResponseField>

<ResponseField name="source" type="string" required>
  Origem do split: `QR_CODE` ou `ACCOUNT_CONFIGURATOIN`.
</ResponseField>

<ResponseField name="grossAmount" type="number" required>
  Valor bruto do cash-in.
</ResponseField>

<ResponseField name="tariffAmount" type="number">
  Valor da tarifa cobrada antes do split, quando aplicável.
</ResponseField>

<ResponseField name="splitBaseAmount" type="number" required>
  Base do cálculo do split após as regras de tarifa.
</ResponseField>

<ResponseField name="createdAt" type="string" required>
  Data de criação da ordem em ISO 8601.
</ResponseField>

<ResponseField name="payouts" type="array">
  Lista dos payouts associados a essa ordem.
</ResponseField>

<RequestExample>
```bash cURL (ordem por id)
curl --location 'https://api.delbank.com.br/api/v1/external/split-payments/orders?id=12345' \
--header 'x-delbank-api-key: {{apiKey}}'
```

```bash cURL (ordem por transação)
curl --location 'https://api.delbank.com.br/api/v1/external/split-payments/orders?transactionId=ID-DO-CASHIN' \
--header 'x-delbank-api-key: {{apiKey}}'
```

```bash cURL (listagem paginada)
curl --location 'https://api.delbank.com.br/api/v1/external/split-payments/orders?page=1&limit=20' \
--header 'x-delbank-api-key: {{apiKey}}'
```

```bash cURL (listagem paginada com metadata)
curl --location 'https://api.delbank.com.br/api/v1/external/split-payments/orders?page=1&limit=10&include=metadata' \
--header 'x-delbank-api-key: {{apiKey}}'
```
</RequestExample>
