---
title: "Consultar recebimento com split"
api: "GET /baas/api/v1/split-payments/orders/{id}"
description: "Consulte um recebimento com split e a lista completa de repasses que ele gerou, com o status de cada um."
tag: "BETA"
---

<Warning>
**Funcionalidade em beta.** Contrato em proposta, sujeito a mudanças. Veja o guia [Acompanhar repasses](/guias/split-pagamentos/acompanhar-repasses).
</Warning>

Retorna o detalhe de um recebimento com split: os valores usados no cálculo e todos os repasses gerados, um por instrução.

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta de recebimento.
</ParamField>

## Path params

<ParamField path="id" type="string" required>
  Identificador do recebimento com split: o id da transação de crédito que gerou os repasses, o mesmo do extrato e do webhook de recebimento.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Identificador do recebimento com split. É o id da transação de crédito que gerou os repasses, o mesmo do extrato e do webhook de recebimento.
</ResponseField>

<ResponseField name="source" type="string">
  `ACCOUNT_CONFIGURATION` (split padrão da conta) ou `QR_CODE` (split por cobrança).
</ResponseField>

<ResponseField name="grossAmount" type="number">
  Valor integral do pagamento recebido.
</ResponseField>

<ResponseField name="tariffAmount" type="number">
  Tarifa de split descontada antes do cálculo. `0` quando não há.
</ResponseField>

<ResponseField name="splitBaseAmount" type="number">
  Base de cálculo dos repasses (`grossAmount - tariffAmount`).
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data e hora do recebimento, em ISO 8601.
</ResponseField>

<ResponseField name="payouts" type="array">
  Repasses gerados pelo recebimento. Cada item tem a estrutura descrita em [Listar repasses](/api-reference/split-pagamentos/listar-repasses#response), exceto o objeto `order`, que não se repete aqui porque os dados do recebimento já estão no nível de cima.
</ResponseField>

## Erros

| HTTP | Código | Quando acontece |
|---|---|---|
| `404` | `SPLIT_PAYMENT_ORDER_NOT_FOUND` | Não existe recebimento com split com esse `id` na conta de recebimento |

<RequestExample>
```bash cURL
curl --location 'https://apisandbox.delbank.com.br/baas/api/v1/split-payments/orders/e7a0c1d2-5b3f-4a8e-9c61-2f4d8b7a1e90' \
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}'
```
</RequestExample>
