---
title: "Listar repasses"
api: "GET /baas/api/v1/split-payments/payouts"
description: "Liste os repasses da conta de recebimento, com filtros por beneficiário, status e data do repasse."
tag: "BETA"
---

<Warning>
**Funcionalidade em beta.** Contrato em proposta, sujeito a mudanças. Veja o guia [Acompanhar repasses](/guias/split-pagamentos/acompanhar-repasses).
</Warning>

Retorna, de forma paginada, os repasses de todos os recebimentos com split da conta de recebimento. Use o filtro `beneficiaryDocument` para mostrar a um beneficiário o histórico dos repasses dele.

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta de recebimento.
</ParamField>

## Query params

<ParamField query="beneficiaryDocument" type="string">
  CPF ou CNPJ do beneficiário, somente números.
</ParamField>

<ParamField query="status" type="string">
  Status do repasse: `SCHEDULED`, `PENDING`, `PROCESSING`, `PAID`, `FAILED` ou `CANCELED`.
</ParamField>

<ParamField query="transferType" type="string">
  Forma do repasse: `INTERNAL` ou `PIX_MANUAL`.
</ParamField>

<ParamField query="paymentDateFrom" type="string">
  Data inicial do repasse, no formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="paymentDateTo" type="string">
  Data final do repasse, no formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="page" type="number" default="1">
  Número da página (começa em 1).
</ParamField>

<ParamField query="limit" type="number" default="20">
  Itens por página. Máximo de 100.
</ParamField>

## Response

Array de repasses. Os dados de paginação vêm no header `Pagination`, descrito em [Paginação](#paginação).

<ResponseField name="id" type="string">
  Identificador do repasse. Use-o para [cancelar o repasse](/api-reference/split-pagamentos/cancelar-repasse).
</ResponseField>
<ResponseField name="status" type="string">
  `SCHEDULED`, `PENDING`, `PROCESSING`, `PAID`, `FAILED` ou `CANCELED`. Veja o significado de cada um em [Status do repasse](/guias/split-pagamentos/acompanhar-repasses#status-do-repasse).
</ResponseField>
<ResponseField name="transferType" type="string">
  `INTERNAL` ou `PIX_MANUAL`.
</ResponseField>
<ResponseField name="instructionType" type="string">
  Tipo da instrução que gerou o repasse: `PERCENTAGE` ou `FIXED`.
</ResponseField>
<ResponseField name="instructionAmount" type="number">
  Percentual ou valor definido na instrução.
</ResponseField>
<ResponseField name="amount" type="number">
  Valor calculado do repasse, em reais.
</ResponseField>
<ResponseField name="paymentDate" type="string">
  Data prevista do repasse, no formato `YYYY-MM-DD`. Nesta fase, é sempre a data do recebimento.
</ResponseField>
<ResponseField name="beneficiary" type="object">
  Beneficiário e conta do beneficiário.

  <Expandable title="beneficiary">
    <ResponseField name="name" type="string">Nome do beneficiário.</ResponseField>
    <ResponseField name="document" type="string">CPF ou CNPJ do beneficiário.</ResponseField>
    <ResponseField name="bankAccountNumber" type="string">Número da conta do beneficiário.</ResponseField>
    <ResponseField name="bankAccountBranch" type="string">Agência da conta do beneficiário.</ResponseField>
    <ResponseField name="participantIspb" type="string">ISPB da instituição da conta do beneficiário.</ResponseField>
    <ResponseField name="bankAccountType" type="string">Tipo da conta do beneficiário: `PAYMENT`, `CURRENT` ou `SAVING`.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="executedTransactionId" type="string">
  Id da transferência que executou o repasse (transferência interna ou Pix). `null` enquanto o repasse não é executado.
</ResponseField>
<ResponseField name="endToEndId" type="string">
  Identificador do Pix, em repasses `PIX_MANUAL`.
</ResponseField>
<ResponseField name="failureReason" type="string">
  Motivo da falha, quando o status é `FAILED`.
</ResponseField>
<ResponseField name="paidAt" type="string">
  Data e hora em que o repasse foi pago, em ISO 8601.
</ResponseField>
<ResponseField name="canceledAt" type="string">
  Data e hora do cancelamento, em ISO 8601.
</ResponseField>
<ResponseField name="cancelReason" type="string">
  Motivo informado no cancelamento.
</ResponseField>
<ResponseField name="createdAt" type="string">
  Data e hora de criação do repasse, em ISO 8601.
</ResponseField>
<ResponseField name="updatedAt" type="string">
  Data e hora da última mudança de status, em ISO 8601.
</ResponseField>

## Paginação

A resposta é um array. Os dados de paginação vêm no header `Pagination`:

```text Header
Pagination: {"currentPage":1,"pageSize":20,"pageCount":1,"rowCount":1,"totalAmount":5.00}
```

| Campo | Descrição |
|---|---|
| `currentPage` | Página retornada |
| `pageSize` | Itens por página (`limit`) |
| `pageCount` | Total de páginas |
| `rowCount` | Total de repasses encontrados |
| `totalAmount` | Soma do `amount` de todos os repasses encontrados, considerando todas as páginas |

```bash cURL
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}'
```
