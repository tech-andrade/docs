<Warning>
**Funcionalidade em beta.** Contrato em proposta, sujeito a mudanças. Veja o guia [Acompanhar repasses](/guias/split-pagamentos/acompanhar-repasses).
</Warning>

Retorna todas as devoluções (*refunds*) de um repasse (*payout*), da mais recente para a mais antiga. Use para acompanhar o resultado de cada Pix de devolução criado em [Devolver parte de um repasse](/api-reference/split-pagamentos/devolver-repasse).

As devoluções também vêm no campo `refunds` de cada repasse em [Consultar ordem de recebimento com split](/api-reference/split-pagamentos/consultar-recebimento).

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta de recebimento.
</ParamField>

## Path params

<ParamField path="payoutId" type="string" required>
  Identificador do repasse (`id`).
</ParamField>

## Response

Array de devoluções, sem paginação. Um repasse vazio retorna `[]`.

Cada item tem a estrutura descrita em [Devolver parte de um repasse](/api-reference/split-pagamentos/devolver-repasse#response): `id`, `payoutId`, `amount`, `status`, `reason`, `requestedBy`, `transactionId`, `endToEndId`, `errorMessage`, `createdAt` e `updatedAt`.

| Status da devolução (`name`) | Significado |
|---|---|
| `PROCESSING` | Pix de devolução enviado, aguardando confirmação. O valor já foi descontado do repasse |
| `SUCCESS` | Valor devolvido ao cliente final |
| `ERROR` | Devolução não concluída. O motivo vem em `errorMessage`, e o valor volta para o `amount` do repasse |

## Erros

| HTTP | Código | Quando acontece |
|---|---|---|
| `404` | `SPLIT_PAYOUT_NOT_FOUND` | Não existe repasse com esse `payoutId` na conta de recebimento |
