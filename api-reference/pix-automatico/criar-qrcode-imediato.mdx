---
title: "Criar QR Code com pagamento imediato"
api: "POST /baas/api/v1/pix/qrcode/recurrences/immediate-payment"
description: "Cria um QR Code composto com uma cobrança imediata e a recorrência (jornada 3). Pagar a cobrança autoriza o Pix Automático."
tag: "BETA"
---

<Note>
Para o passo a passo completo, veja o guia [Jornada 3: pagamento imediato e autorização](/guias/pix/pix-automatico/jornada-3-pagamento-imediato).
</Note>

## Headers

<ParamField header="x-delbank-api-key" type="string" required>
  Sua API key.
</ParamField>

<ParamField header="x-delfinance-account-id" type="string" required>
  Número da conta Delfinance do recebedor.
</ParamField>

## Body

<ParamField body="responseFormat" type="string" default="PAYLOAD_AND_QRCODE">
  `ONLY_PAYLOAD` ou `PAYLOAD_AND_QRCODE`.
</ParamField>

<ParamField body="key" type="string" required>
  Chave Pix da sua conta que recebe o pagamento imediato. Até 77 caracteres.
</ParamField>

<ParamField body="originalAmount" type="number" required>
  Valor do pagamento imediato.
</ParamField>

<ParamField body="city" type="string" required>
  Cidade do recebedor, até 15 caracteres.
</ParamField>

<ParamField body="zipCode" type="string">
  CEP do recebedor.
</ParamField>

<ParamField body="categoryCode" type="string" default="0000">
  Código de categoria (MCC), até 4 caracteres.
</ParamField>

<ParamField body="payerRequest" type="string">
  Mensagem exibida ao pagador, até 140 caracteres.
</ParamField>

<ParamField body="payerDocument" type="string">
  CPF (11 dígitos) ou CNPJ (14 dígitos) do pagador.
</ParamField>

<ParamField body="payerName" type="string">
  Nome do pagador, até 25 caracteres.
</ParamField>

<ParamField body="changeValue" type="string" default="NOT_ALLOWED">
  Se o pagador pode alterar o valor: `NOT_ALLOWED` ou `ALLOWED`. Não envie `null`.
</ParamField>

<ParamField body="qrExpiration" type="number" default="86400">
  Validade da cobrança, em segundos. É também o prazo para o pagador autorizar.
</ParamField>

<ParamField body="additionalData" type="object[]">
  Informações exibidas ao pagador.

  <Expandable title="additionalData">
    <ParamField body="additionalData[].name" type="string">
      Rótulo, até 100 caracteres.
    </ParamField>
    <ParamField body="additionalData[].value" type="string">
      Valor, até 400 caracteres.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="reusable" type="boolean" default="false">
  Se o QR Code pode ser pago mais de uma vez. Mantenha `false` no Pix Automático.
</ParamField>

<ParamField body="recurrenceData" type="object" required>
  Dados da recorrência. Envie todos os campos obrigatórios: neste endpoint, a falta de um deles retorna `500`.

  <Expandable title="recurrenceData">
    <ParamField body="recurrenceData.recurrenceId" type="string">
      Identificador da recorrência, 29 caracteres. Gerado pela API se omitido.
    </ParamField>
    <ParamField body="recurrenceData.frequencyType" type="string" required>
      `WEEKLY`, `MONTHLY`, `QUARTERLY`, `SEMIANNUAL` ou `ANNUAL`.
    </ParamField>
    <ParamField body="recurrenceData.recurrenceStartDate" type="string" required>
      Data da primeira cobrança recorrente, `YYYY-MM-DD`.
    </ParamField>
    <ParamField body="recurrenceData.recurrenceEndDate" type="string">
      Data final, `YYYY-MM-DD`.
    </ParamField>
    <ParamField body="recurrenceData.amount" type="number">
      Valor fixo de cada cobrança. Não envie junto com `minPayerMaxAmount`.
    </ParamField>
    <ParamField body="recurrenceData.minPayerMaxAmount" type="number">
      Piso do valor máximo do pagador, para valor variável.
    </ParamField>
    <ParamField body="recurrenceData.debtor" type="object" required>
      Devedor: `type` (`NATURAL` ou `LEGAL`), `document` e `name`, todos obrigatórios.
    </ParamField>
    <ParamField body="recurrenceData.contractNumber" type="string" required>
      Identificador do contrato, até 35 caracteres.
    </ParamField>
    <ParamField body="recurrenceData.contractDescription" type="string">
      Descrição exibida ao pagador, até 35 caracteres.
    </ParamField>
    <ParamField body="recurrenceData.retry" type="string" required>
      `NOT_ALLOWED` ou `ALLOWED`.
    </ParamField>
  </Expandable>
</ParamField>

## Response

`201 Created`. Os mesmos campos de [Criar QR Code de autorização](/api-reference/pix-automatico/criar-qrcode-autorizacao), com `payloadJws` preenchido com a cobrança imediata.

<RequestExample>
```bash cURL

--header 'Content-Type: application/json' \
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}' \
--data '{
    "key": "e7c3d5f2-4a1b-4c3d-9d15-1b2c3d4e5f60",
    "city": "Sao Paulo",
    "originalAmount": 49.90,
    "qrExpiration": 3600,

}'
```
