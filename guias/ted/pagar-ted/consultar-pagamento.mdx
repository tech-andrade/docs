Você pode consultar o estado de qualquer TED enviada usando a `IdempotencyKey` da requisição original. Os dados chegam primeiro via webhook — use a consulta apenas para reconciliação ou recuperação de falhas.

## Consultar TED

<CodeGroup>
```bash cURL
curl --location 'https://apisandbox.delbank.com.br/baas/api/v2/transfers/ted/{{transferIdentifier}}' \
--header 'x-delbank-api-key: {{apiKey}}' \
--header 'x-delfinance-account-id: {{accountId}}'
```

O `transferIdentifier` é a `IdempotencyKey` enviada no header da criação. Ela também é o `id` da TED, retornado na resposta.

## Status da TED

| Status | Significado |
|---|---|
| `PROCESSING` | TED recebida e aguardando confirmação do SPB |
| `DONE` | TED confirmada pelo SPB e liquidada |
| `CHARGEBACKED` | TED devolvida pela instituição destino |

## Campos da resposta

| Campo | Descrição |
|---|---|
| `id` | Identificador único da TED. É a `IdempotencyKey` enviada na criação |
| `type` | Tipo da transferência: `TED` |
| `status` | Status atual da TED |
| `amount` | Valor transferido |
| `createdAt` | Data de criação da TED |
| `transferAt` | Data da transferência |
| `description` | Descrição enviada na criação |
| `payer` | Dados da conta pagadora |
| `beneficiary` | Dados da conta destino |
| `*.holder` | Documento, nome e tipo (`NATURAL` ou `LEGAL`) do titular |
| `*.participant` | Nome (`name`) e ISPB (`ispb`) do banco |
